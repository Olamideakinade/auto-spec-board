# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v1.4.0] - 2025-03-25

### Added
- Fleet analytics summary panel calculating average horsepower, average price, and total database metrics.
- JSON export and import features for complete data backup and restoration.
- Global keyboard shortcuts (`Ctrl+K` / `Cmd+K`) for rapid search activation.

### Changed
- Optimized DOM rendering loops for instant feedback during filter and sort operations.
- Enhanced mobile layout responsiveness for high-density spec cards.

## [v1.3.0] - 2025-03-01

### Added
- Comprehensive unit testing framework for vehicle operations, validation, and storage.
- Performance benchmarking module to monitor DOM rendering and state manipulation throughput.
- Test runner UI panel for executing verification routines directly.

## [v1.2.0] - 2025-02-25

### Added
- Advanced sorting controls.
