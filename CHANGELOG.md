# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v1.1.0] - 2025-02-18

### Added
- Real-time search input and body style filtering options.
- Persistent storage via browser LocalStorage with fallback defaults.
- Interactive modal dialog for adding new vehicle specifications.
- JSON and CSV data export capabilities.
- Smooth entry animations and micro-interactions on cards.

### Changed
- Overhauled CSS design system with deep dark-mode aesthetic, CSS variables, and modern glassmorphism.
- Refactored core application logic into modular, error-resistant vanilla JavaScript.
- Enhanced mobile responsiveness and touch-friendly control surfaces.

### Fixed
- Layout reflow issues during dynamic card filtering.
- Form validation errors when submitting unformatted numeric values.
