# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v1.2.0] - 2025-02-25

### Added
- Advanced sorting controls (sort by Horsepower, Price, or Make).
- Factory reset option to restore default vehicle specifications.
- Enhanced modal accessibility with focus trapping and ESC key dismissal.
- Glassmorphic card styling with enhanced micro-interactions and smooth entry animations.

### Changed
- Overhauled typography, spacing, and variable-driven color system across `style.css`.
- Refactored `app.js` into modular functions for robust state management and error handling.

### Fixed
- Resolved layout overflow issues on smaller viewports for high-density vehicle spec cards.

## [v1.1.0] - 2025-02-18

### Added
- Real-time search input and body style filtering options.
- Persistent storage via browser LocalStorage with fallback defaults.
- Interactive modal dialog for adding new vehicle specifications.
- JSON and CSV data export capabilities.
- Smooth entry animations and micro-interactions on cards.
